## Repairs completed and preserved

- Fixed the remaining React hydration error on shared 404 fallback documents.
  The fallback is explicitly marked during server rendering and uses client
  rendering. Published pages retain normal hydration of their prerendered HTML.
  A homepage shell cannot otherwise match the navigation state of every missing URL.
- Blog and guide routes have their own shared not-found view inside the existing
  layout. Error pages show the requested path and recover through Go home without
  duplicate headers, footers or robots metadata.
- Fallback noindex metadata is generated by TanStack rather than rewriting HTML
  independently of serialized router state. Tests check that production pages
  remain indexable after returning from a missing page.
- Preserved the earlier clean-build repair: remove only generated `dist/` before
  building, explicitly prerender all 40 public routes and reject incomplete output.
  Guards check one header, footer, main landmark and H1, correct indexing metadata,
  the approved contact address and absence of a shared fallback at a public route.
- Both build scripts use the complete static Pages pipeline. Repeated builds no
  longer retain obsolete article files or duplicate generated redirect rules.
- Contact details are fixed to `mypdffix@gmail.com`; a stale hosting
  `VITE_CONTACT_EMAIL=hello@example.com` cannot override the approved address.
- Preserved corrected merge instructions and added Cloudflare Pages regression
  tests to the read-only CI workflow. Generated Wrangler files are excluded from lint.

Original article JSON, all PDF processing modules, the 25-tool registry, CMS
backend/authenticator configuration, Wrangler deployment configuration, existing
public environment settings and the dependency lockfile remain unchanged.
