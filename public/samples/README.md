# Public PDF Fix Hub practice files

These are intentionally public article examples, generated by
`scripts/create-article-samples.py`. They contain synthetic labels and amounts,
not customer data. They are product/content assets, not test reports.

- `editing-practice.pdf`: three labeled pages, standard text, rotation and mixed sizes.
- `page-order-practice.pdf`: eight clearly numbered source pages.
- `print-practice.pdf`: portrait and landscape A4-sized pages.
- `dark-scan-practice.pdf`: a deliberately dark image-only page, without OCR.
- `embedded-font-practice.pdf`: a subset-embedded DejaVu Sans example.
- `receipt.jpg`, `diagram.png`: real JPG and PNG practice images.
- `dark-scan.jpg`: source image for the dark PDF.

Expected outcomes in articles describe these examples and do not promise results
for arbitrary documents. Preserve these files byte-for-byte in the static build.
